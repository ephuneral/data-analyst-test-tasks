## Задание 4

Имеется база, в которой есть столбец с датой и временем — они указаны по Гринвичу (-3 от МСК). На столбец `start_date` есть индекс. Как оптимизировать следующий запрос, если дата и время на выходе нам нужны уже по МСК:

```sql
declare @start as datetime = '2000-03-01 00:00:00';
declare @end   as datetime = '2000-03-31 23:59:59';

select  name, start_date as time_utc, 
    dateadd(hour, 3, start_date) as time_msk
from DQ.DB.employers
where dateadd(hour, 3, start_date) between @start and @end;
```
